
# Ruby LCM Web API

A lightweight Ruby backend API project developed for Itransition Internship Task #3.

## Project Objective

Build and deploy an HTTP GET endpoint that calculates the Least Common Multiple (LCM) of two non-negative integers.

## Technologies

- Ruby
- Sinatra (planned)
- Bundler
- Git and GitHub
- Automated Testing (planned)

## API Requirements

- Accept `x` and `y` as query parameters.
- Return LCM as plain text containing digits only.
- Return `NaN` for invalid input.
- Deploy the API to a public URL with an email-based endpoint.
